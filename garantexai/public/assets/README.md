Папка `public/assets` предназначена для хранения фотографий и статических изображений.

Как использовать:
- Поместите файлы изображений в эту папку, например `hero.jpg`.
- В приложении Next.js обращайтесь по пути `/assets/hero.jpg` (например, `<img src="/assets/hero.jpg" />`).

Рекомендации:
- Храните оптимизированные версии изображений (webp/avif), по возможности с несколькими размерами для адаптивной загрузки.
- Для больших изображений используйте `next/image` и указывайте `width`/`height` или `fill`.
